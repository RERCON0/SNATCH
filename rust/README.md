# SNATCH (Rust) — CLI + GUI

Оба приложения живут в этом каталоге и делят общий движок (`src/engines.rs`, `config.rs`, `tools.rs`, `setup.rs`):

- **`snatch` / `down`** (`src/bin/snatch-cli.rs`) — терминальный CLI, интерактивный флоу или флаги (`-y -o ...`)
- **`snatch-app`** (`src/bin/snatch-app.rs`) — самостоятельное оконное приложение (~4 МБ, без терминала): двойной клик, вставил ссылку, нажал «Скачать»

## Сборка

```bash
cargo build --release
# -> target/release/snatch.exe, target/release/down.exe, target/release/snatch-app.exe
cargo test
```

## Что умеет GUI

- Тот же ASCII-баннер SNATCH и минималистичный дизайн
- Поле ссылки, авто-выбор движка (yt-dlp / aria2c), формат, куки из браузера
- Папка сохранения выбирается встроенным браузером: клик по папке — войти, «↑ Наверх», «✓ Выбрать эту папку», быстрые кнопки Дом / Рабочий стол / Загрузки / диски — ничего прописывать вручную не нужно
- Прогресс-бар по выводу yt-dlp (`--newline`) и aria2 (`--summary-interval=1`), журнал, отмена
- Если yt-dlp упал с признаками требования авторизации («Sign in to confirm you're not a bot», 403 и т.п.) — кнопка «Повторить с куками из браузера»
- **Авто-установка загрузчиков**: кнопка «Установить загрузчики» скачивает официальные `yt-dlp.exe` (контрольная сумма SHA-512 проверяется) и `aria2c.exe` (win-64bit zip с GitHub) в `%LOCALAPPDATA%\snatch\bin` — ни PATH, ни winget не нужны
- В футере — кликабельная иконка Telegram-канала автора: https://t.me/ArtemMurzin

## Что умеет CLI

Тот же интерактивный флоу (ссылка → движок → формат → папка → подтверждение), плюс `-y`/флаги для запуска без вопросов и `--clear-history`. Детали и таблица флагов — в [корневом README](../README.md).

История ссылок и папок — общий `%LOCALAPPDATA%\snatch\config.json` для CLI и GUI.
