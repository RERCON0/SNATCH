# Командная строка SNATCH

[English](CLI.md) · [Русский](CLI.ru.md)

| Флаг | Что делает |
|---|---|
| `--lang <en|ru>` | Выбрать и сохранить язык; с `--help` показать справку без сохранения |
| `-o, --output <папка>` | Папка сохранения |
| `-j, --jobs <1..16>` | Одновременных загрузок при нескольких ссылках (по умолчанию 3) |
| `-e, --engine {yt-dlp,aria2}` | Движок (по умолчанию — авто-определение) |
| `-f, --format {best,2160p,1440p,1080p,720p,480p,audio,audio-src,subs}` | Формат для yt-dlp (`audio` — mp3 с перекодированием, `audio-src` — исходное аудио без него, `subs` — только субтитры в `.srt`, без видео) |
| `--subs` | Скачивать субтитры рядом с видео (yt-dlp) |
| `--sub-langs <ru,en>` | Языки субтитров (по умолчанию ru,en) |
| `--playlist` | Скачивать плейлист целиком, а не одиночное видео |
| `--yt-dlp-args <ARGS>` | Дополнительные аргументы yt-dlp (строка, как в командной строке) — без ограничений: сюда можно передать и конфиг yt-dlp, и имя выхода, и `--exec`; гарантии безопасности ниже действуют на собственные флаги SNATCH и на белый список `--aria2-args` |
| `--aria2-args <ARGS>` | Дополнительные аргументы aria2c — только безопасный набор: лимиты скорости/соединений, прокси, заголовки, User-Agent/Referer, файл куки (`--load-cookies`), таймауты, повторы. Значение можно писать через `=` или пробелом (`--max-tries=3`, `-x 16`). Флаги, меняющие имя, папку, режим докачки, конфиг или входные файлы, отклоняются вместе с сокращениями |
| `--no-continue` | Перекачать прерванную загрузку yt-dlp с начала (лечит протухший `.part`; aria2 сам проверяет куски по хешам; в GUI повтор с начала происходит автоматически) |
| `--cookies-from-browser <браузер[:профиль]>` | Взять куки из браузера для yt-dlp (chrome, firefox, edge, brave, opera, vivaldi, safari, chromium, whale), например `chrome:Profile 1` |
| `-y, --yes` | Не задавать вопросов (требует url и `-o`) |
| `--clear-history` | Забыть последние ссылки и папки |
| `--install-tools` | Скачать yt-dlp, aria2c, ffmpeg и Deno в собственную папку SNATCH (Windows) |
| `--version` | Версия |

Аудиорежимы по умолчанию встраивают превью и доступные теги из источника. `audio-src` извлекает AAC/Opus без перекодирования (WebM/Opus становится `.opus`). Нужен ffmpeg из `snatch --install-tools`. Если у источника нет картинки, аудио всё равно скачивается. Чтобы отключить обложку, передайте `--yt-dlp-args "--no-embed-thumbnail"`.

Формат `subs` скачивает только субтитры, без видео: ручные и автоматические — на языках из `--sub-langs` (по умолчанию `ru,en`), с конвертацией в `.srt`. Нужен ffmpeg из `snatch --install-tools`; без него yt-dlp сохранит исходный `.vtt`. Если подходящих субтитров нет, задача завершается ошибкой с понятным сообщением: ничего не записывается, а само видео в этом режиме не скачивается никогда.

Если загрузка через yt-dlp не удалась по причине, которую обычно лечат куки (требование входа, бот-детект, возрастные ограничения, лимит запросов 429), интерактивный CLI сам предложит повторить с куками из браузера и даст выбрать браузер из списка. В режиме `-y` вопрос задать нельзя — вместо него выводится подсказка.

## Пути к внешним загрузчикам

```powershell
$env:SNATCH_YT_DLP = "C:\tools\yt-dlp.exe"
$env:SNATCH_ARIA2C = "C:\tools\aria2c.exe"
snatch "magnet:?xt=urn:btih:..."
```

URL и пути с пробелами заключайте в кавычки. Свои аргументы yt-dlp доступны через `--yt-dlp-args`; они включают возможности самого загрузчика, в том числе исполнение команд через `--exec`. Используйте их осознанно. Дополнительные аргументы aria2 ограничены безопасным списком.
